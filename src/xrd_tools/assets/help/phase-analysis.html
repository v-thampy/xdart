How a crystal structure becomes a pattern, and how Phase Analysis fits it

A crystal's lattice fixes where its peaks fall and its atoms fix how strong they are. Phase Analysis computes each phase's whole pattern from its structure and fits all of them to the data at once: the lattice, how much each phase scatters, how broad its peaks are and how its crystallites are oriented. This guide starts with that physics, then shows how each number Phase Analysis reports follows from it.

How Phase Analysis fits

What a fit computes

The phase list

  • One list serves the reference overlays and the fit: a checked phase is drawn and fitted, an unchecked one is neither, and a calibrant is drawn but never fitted.
  • Add CIF… keeps the file's bytes in the phase library; Add lattice… predicts positions only; Add calibrant… and Add from library… list built-in calibrants and kept entries.
  • The minimum intensity drops a CIF phase's reflections weaker than that percent of its strongest one; Same minimum for all phases applies one value to every CIF phase.

Background: what is not crystalline

  • Pre-fit background (SNIP or Chebyshev) is subtracted before the fit and has no free parameters.
  • Fitted background (linear, polynomial, Chebyshev or spline) is refined with the phases.
  • Substrate: a measured substrate pattern, captured with Use displayed as substrate or read with Choose file…, scaled by one free amplitude, alone or plus a linear, polynomial or Chebyshev correction. It must be in q, or convert to it (nm⁻¹ does, 2θ does not); beyond its range its value is held flat.
  • Amorphous peak: one broad peak with a starting centre and σ in Å⁻¹, for glass or other non-crystalline material.

Constraints and the solver

  • Lattice ±% bounds each cell length around its start; cell angles are not refined, and axes that start equal, as symmetry makes them in a cubic or tetragonal cell, stay tied.
  • q-shift bound limits one global shift of every reflection; Cross-phase lock keeps the same axis letter ordered across phases.
  • Drag the fit range on the plot or type it: only those points enter the fit, while the whole trace is drawn.
  • In Advanced, Max iterations caps the solver. Use uncertainties divides each residual by its measured σ, so its least-squares contribution is residual²/σ²; available only when the trace carries measured uncertainties.

Batches, settings and notebooks

  • Batch fits the selected results, or all of them, with the same settings and plots the trend against the result order or a scan column.
  • Sequential starts each fit from the previous one's values; a fit whose reflections differ starts fresh. Turn it off across a phase change.
  • Save settings… and Load settings… keep every option, the phase list and the substrate's file. CIF-based fits export to Jupyter and marimo notebooks that repeat them; manual lattice phases cannot export in the current CIF notebook format. A substrate template must have a reproducible file source whose identity a fit has recorded; an unnamed capture cannot be saved or exported.
